# UNIVERSAL ACCEPTANCE CHECKLIST

A deliverable is not complete until all applicable checks pass.

Architecture:
- [ ] Governing skill identified
- [ ] Dependencies loaded
- [ ] Existing architecture preserved
- [ ] No duplicated system introduced

Frontend:
- [ ] Canonical visual language preserved
- [ ] Living chrome remains dominant
- [ ] No generic cards or flat panels
- [ ] Responsive behavior validated
- [ ] Accessibility behavior validated
- [ ] Performance constraints considered

Backend/API:
- [ ] Contracts typed
- [ ] Ownership enforced
- [ ] Secrets server-side
- [ ] Errors stable and machine-readable
- [ ] Stubs match production contracts

Repository:
- [ ] Build passes
- [ ] Type checks pass
- [ ] Tests pass or failures documented
- [ ] Changed files listed
- [ ] No credentials committed

Delivery:
- [ ] Deployment instructions included
- [ ] Known limitations stated
- [ ] No unsupported completion claims
