# GFX-001 — Living Chrome Graphics System

Mission:
Implement the canonical living intelligent chrome renderer.

Material is:
- metallic
- reflective
- viscous
- cohesive
- physically responsive
- capable of controlled upward flow
- capable of ripple-pool behavior
- continuously alive

Material is not:
- frosted glass
- acrylic
- plastic
- a static gradient
- a generic shader toy
- a flat image overlay

Required systems:
- environment reflections
- Fresnel response
- procedural surface motion
- ripple propagation
- breathing cycle
- state-responsive viscosity
- GPU budget controls
- device fallbacks
- reduced-motion behavior
