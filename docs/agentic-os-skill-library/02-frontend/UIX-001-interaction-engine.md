# UIX-001 — Interaction Experience Engine

Mission:
Make the chrome environment respond as one continuous intelligent surface.

Interactions:
tap, press, long press, drag, swipe, focus, keyboard navigation, voice activation, loading, streaming, interruption, cancellation, recovery.

Rules:
- orb/dock is the primary source of UI growth
- controls emerge from the living surface
- feedback is immediate
- gestures remain reversible where possible
- no dead visual states
- every state has tactile visual response
- device orientation transitions preserve continuity
