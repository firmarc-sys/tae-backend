# Agentic OS Skill Library

Version: 1.0.0  
Authority: Master Architect  
Purpose: Upload-ready knowledge and skill package for Adapt, Claude, repository agents, API agents, and implementation agents.

## Operating Model

This library gives an agent a complete platform-level capability set. Each skill doubles as:

1. A canonical specification.
2. A reusable agent instruction.
3. An implementation contract.
4. A quality and acceptance standard.
5. A governance boundary.

The Master Architect is the sole source of truth. Agents execute; they do not reinterpret, redesign, dilute, or replace canonical requirements.

## Recommended Load Order

1. `00-governance/AOS-000-platform-governor.md`
2. `00-governance/REP-001-repository-governor.md`
3. `00-governance/API-001-api-governor.md`
4. `07-registries/skill-registry.json`
5. Load task-specific skills as required.

## Platform Objective

Build and operate Agentic OS as a living, intelligent, multi-device runtime with:

- TAE orchestration
- GID identity
- liquid chrome visual system
- stateful frontend rendering
- API-driven behavior
- local simulation and production backend compatibility
- PWA installation
- modular apps and services
- secure, observable, testable, deployable architecture

## Universal Execution Rule

Before producing work, the agent must:

1. Identify the governing skill.
2. Load required dependencies.
3. preserve canonical visual and architectural rules.
4. produce deployable artifacts.
5. validate against quality gates.
6. report deviations explicitly.
