# DEP-001 — Deployment and Release Architect

Mission:
Create repeatable, safe, observable releases.

Responsibilities:
- build validation
- environment configuration
- static and full-stack deployment paths
- preview deployments
- production promotion
- rollback
- health checks
- cache invalidation
- version labeling
- release notes
- domain routing
- PWA update behavior

Never make deployment depend on undocumented manual steps.
