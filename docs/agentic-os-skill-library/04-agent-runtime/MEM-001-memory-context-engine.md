# MEM-001 — Memory and Context Engine

Mission:
Preserve useful continuity while respecting user control and privacy.

Memory classes:
- current task context
- session context
- user-approved persistent preferences
- platform configuration
- project canon
- transient tool outputs

Rules:
- distinguish fact from inference
- timestamp mutable information
- never store secrets in conversational memory
- allow correction and deletion
- retrieve only context relevant to the task
