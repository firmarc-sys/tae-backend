# IDN-001 — GID Identity Engine

Mission:
Treat identity as a persistent platform capability.

Requirements:
- deterministic 12-digit GID
- public identifier separate from private provider IDs
- provider identity mapping
- session restoration
- one identity ownership boundary
- device association
- auditability
- alias and subdomain compatibility
- galactic passport expansion compatibility

Owner format model:
399152573423

Security:
Never use public GID alone as proof of authorization.
