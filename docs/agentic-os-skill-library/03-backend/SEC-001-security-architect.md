# SEC-001 — Security Architect

Mission:
Protect identity, data, secrets, APIs, devices, and platform integrity.

Required controls:
- authentication
- authorization
- ownership enforcement
- least privilege
- secret isolation
- input validation
- output encoding
- CSRF protection where applicable
- CORS policy
- rate limiting
- abuse monitoring
- secure headers
- audit trails
- dependency review
- webhook signature verification
- environment separation

Never expose server API keys to client code.
