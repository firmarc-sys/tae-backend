# TAE Pantheon Activation

TAE is the sole resolver for the United Agentic Ecosystem pantheon. Every canonical deity may be resolved from `src/pantheon/deityRoster.ts`, authority-gated through Ma’at, manifested by Mercury, executed through ARI when provider work is required, and returned to TAE as continuity state.

Canonical activation path:

```text
HUMAN INTENT
→ JAHORIN
→ TAE RESOLUTION
→ MA’AT AUTHORITY GATE
→ PRIMARY DEITY + SUPPORTING COUNCIL
→ MERCURY MANIFESTATION
→ SKILL / TOOL EXECUTION
→ ARI WHEN EXTERNAL EXECUTION IS REQUIRED
→ RESULT
→ TAE CONTINUITY EVENT
→ JAHORIN REMAINS
```

The former browser `capabilityResolver` is compatibility-only for the legacy executable subset. New pantheon activation must use `src/tae/resolvePantheonIntent.ts`.
