# Jahorin Trismegistus Manifest Orchestration Contract

Human input converges on `POST /api/runtime`.

Canonical execution path:

human intent -> Jahorin -> Ma'at verification -> TAE sequencing -> capability selection -> execution -> verified result -> Mercury state -> NovaLife continuity.

Successful responses contain `ok:true`, `request_id`, `capability`, `status`, and `result`. Failures contain `ok:false`, `request_id`, `capability`, `status:"error"`, a stable `code`, a concrete `error`, and a useful `next_action`. A bare `500` is never an acceptable application response.

The visible machine family remains Wepwawet, Hathor, Ptah, Thoth and Horus beneath Trismegistus. Ma'at, Hephaestus, TAE, Mercury and NovaLife operate beneath the interface rather than becoming extra navigation surfaces.
